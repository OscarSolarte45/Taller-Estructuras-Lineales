## Descripción del taller

Este taller fue desarrollado en Java y tiene como objetivo practicar el uso de arreglos unidimensionales, ArrayList y matrices.

Los ejercicios incluyen generación de datos aleatorios, recorrido y procesamiento de estructuras, factoriales, búsquedas, ordenamiento, frecuencias y diferentes operaciones con matrices.

## Instrucciones para ejecutar el programa

### Requisitos

- Tener instalado Java JDK.
- Tener instalado NetBeans o Visual Studio Code.

### Ejecución desde consola

1. Clonar o descargar este repositorio.
2. Abrir una terminal dentro de la carpeta del proyecto.
3. Compilar el ejercicio que se desea ejecutar.
4. Ejecutar la clase correspondiente.

Por ejemplo, para ejecutar el ejercicio 1:

```bash
javac -d out src/arreglos/Ejercicio01Primos.java
java -cp out arreglos.Ejercicio01Primos
```
